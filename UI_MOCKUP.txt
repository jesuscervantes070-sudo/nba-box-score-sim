================================================================================================
 QUESTIONS FOR YOU
================================================================================================

 1. RETRO FONT.  A terminal uses whatever font the user's terminal is set to -- we can't
    change it.  So "pixel/retro" can mean either (a) big ASCII banners + color inside the
    terminal, as drawn above, or (b) leaving the terminal for a real window (pygame or a web
    page) where we control the font completely.  (b) is a much bigger project and would mean
    rewriting main.py's 2,000 lines of printing.  Which one are you picturing?

 2. TEAM OVERALL.  Your team-select notes want a team rating.  We have no such number and it
    would have to be invented and calibrated (a 1-99 from real stats).  Build it, or show the
    starting five and their real numbers instead?

 3. SEASON NOTES.  "Lockout", "COVID", "Bobcats join" etc. would be a small hardcoded table
    (~10 seasons of real one-liners).  Worth it?

 4. WHERE THE OLD MENU GOES.  main.py today opens with single game / full season / multi-
    season.  In this design, "History Sim" covers all three (a single season is just a run of
    length one).  Do we drop the single-exhibition-game option, or keep it as a 5th mode?

 5. HOW WE BUILD IT.  This is a big re-dress of a working 2,000-line file.  I'd do it one
    screen at a time, top to bottom, running it after each -- title/menu first, and nothing
    below it touched until you've seen the one above it work.  OK?
